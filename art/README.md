# 美术资源目录

游戏按下面的路径和文件名读取美术。把文件放到对应位置，用 Godot 打开项目时会自动导入，不需要改代码。
带“可选”的位置：放了文件就用你的图，没放就用占位图。

| 目录 | 放什么 | 游戏里用在哪 |
| --- | --- | --- |
| `backgrounds/` | 整幅背景图 | 战斗舞台、脑海区、商店和休息处的底图 |
| `characters/player/` | 玩家角色（第一人称的手）的动画帧 | 战斗舞台左下 |
| `characters/enemies/` | 敌人立绘（可选） | 战斗舞台中央的法阵上 |
| `icons/spells/` | 法术图标（可选） | 法术卡左侧 |
| `icons/relics/` | 遗物图标（可选） | 血条下方、休息处 |
| `icons/affixes/` | 词条图标（可选） | 词云和符文牌上的小徽记 |
| `ui/` | UI 组件图集和切好的组件 | 所有面板、按钮、云朵、符文牌 |
| `concept/` | 效果图、版式图 | 只作参考，游戏不读取，也不打包进导出版本 |

通用要求：

- 角色、图标一律用带透明背景的 PNG。
- 文件名用小写英文加下划线，必须和各目录 README 里写的一致。
