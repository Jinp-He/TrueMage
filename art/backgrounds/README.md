# 背景

| 文件名 | 用途 | 尺寸 |
| --- | --- | --- |
| `battle_stage.png` | 战斗舞台。游戏会裁出中下部一条（宽高比约 4.6:1）铺满舞台 | 现为 1983×793 |
| `mind_area.webp` | 商店、休息处的背景 | 现为 1672×941 |
| `screen_backdrop.png` | 战斗画面最底层的深色底图 | 1600×900 |
| `battle_arena.png` | 战斗舞台（新版），整张铺满上方舞台区 | 1600×352 |
| `build_area.png` | 咒语构筑区的羊皮纸底 | 1171×208 |
| `mind_clouds.png` | 灵感碎片区的星云底 | 1201×318 |

替换时保持文件名不变即可。新版战斗美术按 1600×900 画，游戏放大 1.045 倍铺满 1672×941；四块面板的边框是 `art/ui/layout/battle_frame.png`。`battle_stage.png` 是旧版舞台，战斗已不再使用。
