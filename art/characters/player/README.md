# 玩家角色

每个动画一个子目录，里面是按顺序编号的帧：`frame_000.png`、`frame_001.png`……（透明 PNG，所有帧画布大小一致、对齐不变）。

| 子目录 | 内容 | 帧的用法 |
| --- | --- | --- |
| `hand_wand/` | 第一人称持杖的手，8 帧，535×463 | 0～2 帧循环做待机，3～7 帧在释放时播放 |

`hand_wand` 里的 `README.txt`、`timing.json`、`spritesheet_4x2.png` 是导出工具附带的说明和整张精灵图，游戏只读取逐帧的 PNG。

`hands.png`（436×249）是新版战斗用的第一人称双手（左手持杖），静态图，待机晃动和施法举杖由代码做补间动画。`hand_wand/` 的逐帧动画目前不再使用。
