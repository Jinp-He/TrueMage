# 敌人立绘（可选）

放一张透明背景的 PNG，文件名用敌人的 id。没放的敌人，战斗中显示名牌占位。

| 文件名 | 敌人 |
| --- | --- |
| `skeleton_apprentice.png` | 骷髅学徒 |
| `graveyard_wizard.png` | 墓园巫师 |
| `bound_monk.png` | 咒缚僧侣 |
| `darkmoon_priest.png` | 暗月祭司 |
| `bone_archmage.png` | 骸骨大法师 |

建议：角色站立全身，脚底贴着画布下边缘，高度 600 像素左右。游戏会把它等比缩放进舞台中央法阵上方约 420×340 的区域。
